Troubleshooting

Keep the failure visible.

Start with the installed package version, the exact refusal code and the state of the evidence. Do not turn a successful command into a broader success claim.

The observa command is missing or belongs to another package.

After installing OpenClaw v0.7.4, restart its gateway to create the managed launcher. The plugin will not overwrite an existing Local Node or unrelated observa executable. Read the versioned README’s collision instructions and use its direct CLI path for inspection. Do not uninstall a working runtime package just to guess at a fix.

observa --version
observa --help

If this reports Local Node when you intended OpenClaw, stop and resolve the command selection first.

Status looks configured, but Hosted has no evidence.

Local status reports local configuration and available evidence. It is not a live Hosted probe. For OpenClaw, use observa hosted-health after pairing; review stale heartbeat, binding, credential or control refusals before drawing conclusions.

For Local Node, confirm the service is started, its approved composition is installed and the n8n service loaded the generated hook environment. Run one synthetic workflow and inspect the paired Hosted workspace. A local diagnose result alone is insufficient.

n8n is still using an earlier hook.

n8n keeps the hook loaded at process start. After changing Local Node versions, regenerate the hook with observa n8n-setup, restart n8n, run one workflow and then run observa diagnose. The loaded hook is unknown until n8n reports an execution.

Use Local Node 0.1.7’s documented stop/start procedure from the package README for an upgrade. A stale process or occupied loopback port can make start fail; do not treat the package version on disk as the running service version.

The run completed, but no decision or outcome is confirmed.

Check whether this action was observed, mapped and evaluated as separate questions. Unmapped evidence is not a governance verdict. n8n partial editor runs, pinned results and carried results have specific exclusions; missing workflow revision can prevent revision-bound evaluation.

A runtime COMPLETED result does not confirm the business outcome. Missing evidence remains uncertain. Preserve the refusal code or warning and share only a redacted summary.
